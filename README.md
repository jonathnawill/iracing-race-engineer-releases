# Race Engineer — Releases

This repository holds **binary release artifacts only** for
[Race Engineer](https://github.com/jonathnawill/iracing-race-engineer), an
independent third-party companion app for iRacing (fuel strategy, pit
stops, telemetry). No source code is published here.

Each release contains:
- IracingRaceEngineer.Wpf-win-x64-vX.Y.Z.zip — the app + updater, self-contained win-x64
- manifest.json — version, download URL, SHA-256, size, used by the app's auto-updater

Race Engineer is not affiliated with or endorsed by iRacing.
